# Deep-Fried Mème Studio

Une application mobile React Native / Expo inspirée du prototype de studio de création de mèmes "deep-fried".

## Fonctionnalités

- Choix d’image depuis la galerie
- Contrôles de cuisson, saturation et contraste
- Texte en haut et en bas avec couleurs et options de style
- Stickers emoji
- Vignette / fumée / effets visuels
- Export de la création dans la galerie du téléphone

## Prérequis

- Node.js 18+
- npm ou yarn
- Expo Go sur un appareil mobile, ou un émulateur Android/iOS

## Installation

```bash
npm install
npm start
```

Puis ouvrez l’application dans :
- Expo Go sur Android / iPhone
- ou émulateur via Android Studio

## Scripts

```bash
npm start
npm run android
npm run ios
```

## Notes

Cette version est conçue comme un prototype mobile fonctionnel avec un rendu visuel inspiré du concept original, prêt à être enrichi avec des effets d’image plus avancés si vous voulez aller vers une version premium.
